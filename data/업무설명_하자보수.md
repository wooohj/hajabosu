# 하자보수 업무 설명 (시설관리팀 담당자 메모)

※ 실습용 가상 업무입니다. 업체명·공사 정보는 모두 가상입니다.

## 1. 지금 일하는 방식
- 하자 접수는 현장 순찰 메모, 다른 팀 메일, 메신저로 들어온다. 형식이 제각각이다. (`접수함` 폴더)
- 담당자가 하나씩 읽고 하자대장(엑셀)에 옮겨 적는다.
- 공사정보(`공사정보.csv`)를 찾아 보증기간 안인지 확인하고, 보증기간 안이면 시공업체에 보수 요청 공문을 보낸다.
- 매주 금요일 주간 하자현황을 팀장에게 보고한다.
- 건당 15~20분, 주 10~20건이라 매주 반나절 이상 걸린다.

## 2. 하자대장에 적는 항목
접수번호, 접수일, 원문파일, 위치, 공종, 하자내용, 긴급도, 조치기한, 공사번호, 시공업체, 준공일, 보증만료일, 보증판정, 책임구분, 상태, 비고

- 접수번호: `HJ-접수일(YYYYMMDD)-순번(01부터)` 예) HJ-20261102-01
- 접수일: 원문에 적힌 날짜. 없으면 파일명 앞의 날짜.
- 위치: `층 구역` (예: B1 푸드코트, 2F 화장실). 매장 번호·기둥 번호·남녀 구분 같은 세부 위치는 하자내용에 적는다.
- 하자내용: 40자 이내 요약

## 3. 공종 판단
| 공종 | 원문 단서 |
|---|---|
| 방수 | 누수, 천장에서 물 떨어짐 |
| 타일 | 타일 들뜸·깨짐·줄눈, 바닥 기울기 |
| 전기 | 조명, 콘센트, 분전반, 누전, 전원 |
| 설비 | 배관, 배수 막힘, 급수, 수전 |
| 기계 | 자동문, 셔터, 주차 차단기, 엘리베이터, 에스컬레이터 |
| 도장 | 페인트 벗겨짐·변색 |
| 바닥재 | 에폭시, 바닥 코팅, 장판 |
- 원문만으로 알 수 없으면 후보 공종을 `설비/타일`처럼 함께 적고, 담당자가 현장을 보고 정한다.

## 4. 긴급도와 조치기한
| 긴급도 | 기준 | 조치기한 |
|---|---|---|
| 긴급 | 누수, 전기 이상, 고객 안전 위험(넘어짐·미끄러짐·추락) | 접수일 + 1일 |
| 높음 | 고객 출입·영업 지장 (출입문·자동문·주차 출구 이상, 고객 시설 사용 불가, 고객 민원) | 접수일 + 3일 |
| 보통 | 그 외 (미관, 운영 지장 없음) | 접수일 + 7일 |
- 고객 = 이용 고객. 입점 매장의 문의는 고객 민원에 포함하지 않는다.

## 5. 보증 판정
- 공사정보에서 위치와 공종이 모두 같은 공사를 찾는다.
- 보증만료일 = 준공일 + 하자보증기간(년)
- 판정 기준은 오늘이 아니라 **접수일**이다.
  - 접수일이 보증만료일 이전(같은 날 포함) → 보증내 → 책임구분 `시공업체`
  - 보증만료일이 지남 → 보증만료 → 책임구분 `자체보수`
  - 맞는 공사가 없거나 2건 이상, 공종 미정 → `확인필요` (담당자가 확인)
- 보증내인데 보증만료일까지 30일 이내로 남았으면 비고에 `만료임박`을 적는다. 만료 전에 꼭 요청해야 한다.
- 확인필요 건도 후보 공사가 만료임박이면 비고에 함께 적는다.

## 6. 처리 상태
접수 → 판정완료(또는 확인필요) → 조치요청

## 7. 결과물
- 시공업체 하자보수 요청 공문: 업체당 1개, 같은 업체 여러 건은 한 공문에 표로
  - 공문은 `data/양식/공문양식.docx`를 채워 Word로 만든다. 문서번호는 `시설-YYYY-순번`(예: 시설-2026-001), 업체별 1건.
- 조치 일정: 조치기한을 캘린더에 등록 (.ics 파일)
- 주간 하자현황 보고: 첫 줄에 결론, 긴급 건 / 업체 요청 건 / 자체보수 건 / 확인필요 건
